01 / WORKFLOW

Простая цепочка — полезный ответA simple path to a useful answer

Бот опирается на решения людей, которые уже помогли в этом чате.The bot relies on answers already confirmed by people in this chat.

01
?

Участник спрашиваетSomeone asks

В группе появляется текстовый вопрос. Бот не импортирует старую переписку.A text question appears in the group. Old chat history is not imported.

02
↳

Администратор подтверждаетAn admin confirms

Администратор отвечает на вопрос, затем отвечает на свой ответ командой /solve.An admin replies to the question, then replies to their own answer with /solve.

03
↗

Бот даёт ссылкуThe bot links back

На похожий новый вопрос он показывает одно лучшее решение — если сходство достаточно высокое.For a similar new question, it shows the single best solution when similarity is high enough.

02 / PRINCIPLES

Предсказуемый поиск вместо догадокGrounded search instead of guesses

◎

Только этот чатChat by chat

Решения разных чатов изолированы. Каждый чат настраивает собственный порог совпадения.Solutions stay isolated by chat. Each chat has its own similarity threshold.

≋

Локальная модельLocal model

FastEmbed и multilingual E5 сравнивают вопросы по смыслу. Модель не сочиняет ответы.FastEmbed and multilingual E5 compare questions by meaning. The model does not write answers.

◇

Минимум данныхMinimal data

В SQLite попадают подтверждённые пары, оценки и настройки — не вся история сообщений.SQLite stores confirmed pairs, feedback, and settings — not the whole chat history.

✳

Контроль администратораAdmin control

Администратор подтверждает решения, меняет порог и удаляет данные чата через /forget.Admins confirm solutions, change the threshold, and remove chat data with /forget.

03 / GET STARTED

Запустите у себяRun it yourself

Python 3.12, aiogram 3, SQLite и Docker Compose. Токен Telegram остаётся в локальном .env; контейнер не открывает входящие порты.Python 3.12, aiogram 3, SQLite, and Docker Compose. Your Telegram token stays in a local .env; the container exposes no inbound ports.
