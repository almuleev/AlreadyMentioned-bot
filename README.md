# AlreadyMentioned

**Русский** · [English](README.en.md)

AlreadyMentioned — самостоятельно размещаемый Telegram-бот для чатов поддержки. Он находит ранее подтверждённый ответ и даёт ссылку на него; новые ответы не генерирует.

**Статус: локальный MVP.** Администратор сохраняет текстовую пару «вопрос → ответ» командой `/solve`. Бот сравнивает новые вопросы на русском языке только с решениями того же чата и предлагает одну ссылку, если сходство достигает порога этого чата. Основной сценарий проверен в тестовой супергруппе Telegram.

Подробные правила работы, настройка порога и объяснение оценок сходства — в [руководстве на русском](docs/GUIDE.ru.md).

[Сайт проекта](https://almuleev.github.io/AlreadyMentioned-bot/) · [Репозиторий на GitHub](https://github.com/almuleev/AlreadyMentioned-bot)

## Структура

- `src/already_mentioned/bot/` — создание aiogram-бота и проверка прав.
- `src/already_mentioned/handlers/` — команды, сообщения и кнопки оценки.
- `src/already_mentioned/services/` — временная память reply-цепочек, фильтр вопросов, локальные embeddings и поиск.
- `src/already_mentioned/database/` — подключение к SQLite и схема таблиц.
- `src/already_mentioned/repositories/` — операции с данными чатов, решений и оценок.
- `src/already_mentioned/models/` — структуры данных, возвращаемые репозиториями.
- `tests/` — автономные тесты без Telegram-токена и скачивания модели.

## Локальная установка (Python 3.12)

В PowerShell из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

Заполните `TELEGRAM_BOT_TOKEN` в локальном `.env`. Путь к базе `DATABASE_PATH` по умолчанию — `data/already_mentioned.db`. Не добавляйте `.env` в Git. Если в Windows или переменных окружения настроен HTTPS-прокси, бот использует его для Telegram. При первом `/solve` модель скачивается в игнорируемую папку `models/`, затем вычисления выполняются локально вне основного event loop. Импорт модулей и тесты модель не скачивают.

Для `/solve` бот должен получать обычные сообщения группы: отключите Privacy Mode в BotFather. Публичные и приватные **супергруппы** дают прямые ссылки на сообщения; в обычной группе Telegram такой ссылки не предоставляет, поэтому сохранить решение там нельзя. Подходящий ответ администратора хранится только в памяти до 6 часов или до перезапуска бота; одновременно бот помнит не более 5000 таких цепочек.

Команды: `/start` и `/help` показывают справку; `/status` — число решений и текущий порог; `/threshold 0.88` меняет порог этого чата (только администратор); `/forget` запрашивает подтверждение удаления решений и оценок этого чата (только администратор). Под предложением ответа есть кнопки **👍 Помогло** и **👎 Не подходит**; один пользователь может оценить одно предложение один раз. Начальный порог нового чата — 0,88.

Запуск long polling:

```powershell
python -m already_mentioned.main
```

## Docker Compose (локальное развёртывание)

Нужен Docker Desktop с Linux-контейнерами и Compose. Токен остаётся в игнорируемом файле `.env`. Перед запуском контейнера остановите локальный Python-процесс: один и тот же токен должен опрашивать Telegram только из одного процесса.

```powershell
docker compose build
docker compose up -d
docker compose logs -f bot
```

`docker compose down` останавливает контейнер. Именованные тома `bot_data` и `model_cache` сохраняют SQLite-базу и модель между запусками. **Не используйте `down --volumes`, если хотите сохранить данные.** У Docker отдельные база и кэш: файлы из Windows-папок `data/` и `models/` автоматически не импортируются. Порты наружу не открываются.

Чтобы посмотреть численную оценку сходства для вопроса, выполните `docker compose exec -T bot python -m already_mentioned.diagnostics "Ваш вопрос здесь?"`. Подробности — в [руководстве](docs/GUIDE.ru.md#как-посмотреть-значение-самому).

Если Telegram доступен только через прокси, задайте в `.env` переменную `HTTPS_PROXY` с адресом, доступным контейнеру. Для прокси, работающего на Windows `127.0.0.1`, может понадобиться `host.docker.internal` с тем же портом. Не публикуйте адрес прокси вместе с секретами.

## Проверки и приватность

Проверки не требуют токена:

```powershell
ruff check .
pytest
```

Бот сохраняет только подтверждённые администратором пары «вопрос → решение», оценки и минимальные настройки чатов — **не всю историю переписки и не имена пользователей**. Таблицы создаются при запуске. `/forget` удаляет решения и оценки текущего чата только после подтверждения кнопкой; настройка порога остаётся. В `tests/fixtures/questions.py` есть 80 синтетических сообщений для автономных проверок. Эти тесты используют фиктивные векторы и не измеряют точность настоящей модели.
